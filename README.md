# Murdoku

Puzle de asesinatos sobre el plano de una mansión. Coloca a cada persona según su declaración (una por fila y columna) y descubre quién estuvo a solas con la víctima.

**Jugar:** https://jorge-esteban.github.io/murdoku/

- 5 dificultades (de 5×5 a 9×9) y un caso del día
- Casos generados al momento, siempre con solución única
- Pistas que explican el razonamiento paso a paso
- Sin dependencias: HTML, CSS y JavaScript puros
